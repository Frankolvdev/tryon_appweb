# 01B · App Shell y navegación privada

Este ZIP es incremental sobre `01A_appweb_foundation_auth.zip`.

Incluye:
- validación centralizada de sesión mediante `/users/me` ya usado por la base;
- navegación privada responsive con drawer móvil;
- perfil y cierre de sesión en la barra lateral;
- dashboard renovado con accesos reales a rutas internas;
- rutas para Try-On, historial, galería, tokens y configuración sin datos simulados;
- vistas de cuenta que muestran únicamente información disponible en el usuario autenticado.

Las secciones todavía no conectadas indican explícitamente su estado para evitar botones o resultados ficticios.
