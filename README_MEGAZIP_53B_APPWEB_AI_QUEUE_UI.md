# MegaZIP 53B — AppWeb

Integra la experiencia de cola unificada.

- Muestra proveedor, cola, posición y job remoto cuando estén disponibles.
- Permite enviar otro trabajo aunque exista una ejecución activa; el nuevo trabajo queda bajo control del orquestador.
- Los assets de cada ejecución permanecen asociados a su job.
- El indicador global sigue rastreando todas las ejecuciones activas.

Los campos nuevos son opcionales para mantener compatibilidad durante el despliegue incremental.
