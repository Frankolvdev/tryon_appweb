# Models — Bubble Butt bajo el slider Breasts

Base exacta:
tryon_appweb-main (81).zip

Cambios SOLO en Models:
- Quita de la imagen principal:
  VARIANTE ACTUAL + nombre + valores Hips/Fat/Breasts.
- Oculta Skin tone y Hair length.
- Quita la leyenda de la siguiente fase.
- Bajo Breasts muestra 4 slots Bubble Butt según el Body Proportions actual.
- Variante 1 se etiqueta visualmente como Default.
- Al cambiar el cuerpo, consulta automáticamente las Bubble Butt de esa combinación Fat x Hips.
- Usa ModelImage para lazy load/placeholder real hasta que la imagen cargue.
- Mientras se obtiene el catálogo, aparecen 4 placeholders animados.
- Si una variante aún no está publicada, muestra "Sin preview".
- Todas las imágenes del módulo Models reutilizan un sweep luminoso al hover inspirado en la animación ya existente de Billing (`tokenCardSweep`).
- No cambia sliders, galería, administración de modelos, navegación ni "Usar este cuerpo".
- La elección Bubble Butt NO se persiste todavía; este alcance es únicamente la relación/previsualización solicitada.

No se modifican otros módulos AppWeb.
